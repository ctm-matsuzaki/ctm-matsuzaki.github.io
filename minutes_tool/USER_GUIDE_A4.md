# 議事録作成ツール 使い方（v1.0.0）

## 1. 起動する

Windowsでは `議事録作成ツール.exe`、Macでは `議事録作成ツール.app` を開きます。
Pythonで起動する場合は、プロジェクトフォルダで次のコマンドを実行します。

```bash
python3 run_minutes_tool.py
```

## 2. 議事録テキストを貼り付ける

画面中央の大きな入力欄に、AIで作成した議事録テキストをそのまま貼り付けます。
想定している見出しは、`基本情報`、`議題①`、`ToDo`、`次回会議` です。

## 3. Excelを作成する

画面下部の `Excel作成` ボタンを押します。
保存先を選ぶ画面が表示されるので、保存したい場所とファイル名を指定します。

## 4. 完了を確認する

作成が終わると、`作成完了` のメッセージと保存先が表示されます。
表示された保存先にExcelファイルが作成されていることを確認してください。

## 5. よくあるエラー

### テンプレートが見つからない

テンプレート選択画面が表示されたら、`会議議事録テンプレ.xlsx` を選択してください。

### Excelを保存できない

同じ名前のExcelファイルを開いている場合は閉じてから再実行してください。
保存先フォルダに書き込み権限があるかも確認してください。

### 黄色セルが表示される

自動判定できなかった項目です。Excel上で内容を追記してください。

## 6. ボタンの意味

- `Excel作成`: 貼り付けた議事録からExcelを作成します。
- `クリア`: 入力欄を空にします。
- `終了`: ツールを閉じます。
