# CTM Web Project

## Project Purpose

This project is the official website of Clinic Total Management (CTM).

The objective is to build and maintain a website that earns trust from clinic directors, administrators, and healthcare executives.

Every change should improve clarity, credibility, usability, and inquiry conversion.

Always prioritize:

1. User instructions
2. Trust and credibility
3. Inquiry conversion
4. AI search optimization
5. SEO
6. Maintainability

---

## Core Principles

- Follow the user's instructions accurately.
- Keep changes as small as possible.
- Do not modify unrelated sections.
- Do not assume facts or create fictional information.
- If requirements are unclear, ask before implementing.
- Improve existing work instead of replacing it whenever possible.

Never surprise the user with unexpected design or content changes.

---

## Design Principles

The website should always feel:

- Professional
- Calm
- Trustworthy
- Clean
- Consistent
- Easy to read

Avoid:

- Flashy design
- Excessive animation
- Aggressive marketing language
- Overly decorative layouts

Design decisions should improve trust rather than attract attention.

---

## Visual Consistency

Always review the entire page, not only the modified section.

Maintain visual consistency for:

- spacing
- alignment
- typography
- image size
- icon size
- card height
- table width
- section spacing

Images, text, tables, cards and other content should appear visually balanced.

When images are placed beside text or tables, adjust their size so that neither side appears noticeably larger or smaller.

Avoid layouts where different elements create uneven heights, widths or empty space.

If multiple cards or sections belong to the same group, they should feel like parts of one design system.

---

## AI Search & SEO

Create pages that are easy for both people and AI search systems to understand.

Always:

- Keep one primary topic per page.
- Use meaningful headings.
- Write clear and direct sentences.
- Explain technical terms when appropriate.
- Preserve existing SEO structure whenever possible.
- Preserve metadata unless instructed otherwise.

Avoid:

- Duplicate content
- Ambiguous wording
- Unsupported claims
- Keyword stuffing

---

## Development Rules

- Prefer improving existing code.
- Avoid unnecessary refactoring.
- Preserve existing functionality.
- Keep HTML, CSS and JavaScript clean and readable.
- Minimize the impact of every change.
- Do not modify unrelated files.
- Do not remove existing content unless instructed.

---

## Self Review

Before reporting completion, confirm:

- The requested work is complete.
- No unrelated sections were modified.
- The page remains visually consistent.
- Desktop layout is correct.
- Mobile layout is correct.
- Images and text remain balanced.
- No obvious layout issues were introduced.
- No obvious errors were introduced.

If an issue is found, fix it before reporting completion.

---

## Reporting

After every task, report:

- Files changed
- Summary of changes
- Checks performed
- Manual confirmation required (if any)

Keep reports concise and easy to review.
